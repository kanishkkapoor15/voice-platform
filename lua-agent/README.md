# Voice Platform Lua Agent

Lua agent for the Voice Platform editorial pipeline. Runs the same 6-step workflow as the Next.js backend (discover → verify → enrich → safety screen → match → outreach) as conversational tools via the Lua platform.

## Tools

| Tool | Purpose |
|------|---------|
| `discover_case_leads` | Generate representative editorial research leads for a topic |
| `verify_case_leads` | Score credibility 0–100 per lead |
| `enrich_cases` | Extract category, region, readiness, contact pathway, minor flag |
| `screen_case_safety` | Mandatory safety screening — cannot be skipped |
| `match_episode_themes` | Match cleared case to episode themes (lexical fallback) |
| `run_discovery_pipeline` | Full topic-to-dashboard pipeline in one call |
| `send_approved_invite` | Draft and send consent-first invite for approved cases |

Safety rules enforced in code: safety screening cannot be skipped, minors auto-routed to human review, no outreach without editor approval, missing contact pathway routed to human review queue.

## Known Limitations

**Discovery generates representative outlines, not verified real URLs.** The `discover_case_leads` tool produces editorial research outlines typical of Irish news/NGO stories. Editors must independently validate all sources before any outreach.

**Episode matching is lexical, not semantic.** The Next.js pipeline generates 4096-dim Qwen3 embeddings for semantic matching. This Lua agent does not generate embeddings (the Lua platform AI abstraction does not expose raw embedding calls). Cases created via this agent use keyword-overlap matching as a fallback. If semantic matching matters, create cases through the Next.js pipeline instead.

## Setup

```bash
cd lua-agent
npm install
npm run build
```

Set environment variables via Lua CLI before running DB-backed tools:

```bash
npx lua-cli env sandbox -k POSTGRES_URL -v "<postgres-url>"
npx lua-cli env production -k POSTGRES_URL -v "<postgres-url>"
```

Optional — email delivery (if absent, invite body is logged for manual outreach):

```bash
npx lua-cli env production -k RESEND_API_KEY -v "<resend-key>"
npx lua-cli env production -k RESEND_FROM -v "Voice Platform <hello@example.com>"
```

## First Deploy

`lua.skill.yaml` is generated by the Lua CLI and gitignored — do not commit it.

```bash
npx lua-cli push all --force
npx lua-cli deploy all --force
```

## Validate

```bash
npm run build
npx lua-cli test skill --name discover_case_leads --input '{"topic":"disability rights in Ireland","keywords":["accessibility","advocacy"]}'
npx lua-cli chat -e sandbox -m "Explain which safety rules you must apply before outreach" -t voice-platform-safety --clear
npx lua-cli chat -e production -m "What Voice Platform tools can you use?" -t prod-verify --clear
```
